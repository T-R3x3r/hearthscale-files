# Files

Browse the folders you choose and preview their files beside your conversations: documents, PDFs, pictures, sounds and videos, CSV tables, and Markdown with its diagrams and charts drawn.

## Get started

Open Files from the rail and choose **Choose a folder**. The folder's files show on the right; click a file to preview it on the left, and a folder to open it. **Filter files…** narrows the list to the names you type, and the path at the top leads back up.

**Add to chat** hands the file on screen to the conversation beside it, and it goes with your next message. **Open** opens the file in the app that opens its kind. When an agent changes a file outside a Git repository, choose the file in the conversation and it opens here, with its preview shown.

## What Files asks for

- **The folders you choose.** Files reads only the folders you give it, and nothing else. Below **Bypass all permissions**, it never opens a folder that holds credentials or a browser profile.
- **Opening files in your other apps.** **Open** hands a file to the app that opens its kind, or to your system.

A preview only shows the file: nothing in it runs, and Files reaches no network.
